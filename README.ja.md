<h1 align="center">StartMenu4Mac</h1>

<p align="center">インストール済みアプリとピン留めアイテム（アプリやフォルダ）を並べて表示できる、Windowsのスタートメニュー風のmacOSアプリ。</p>

[English](README.md)

<p align="center">
  <img src="Screenshots/startmenu4mac-apps-view.png" alt="StartMenu4Macでアルファベット順のアプリ一覧とピン留め項目を表示した画面" width="840">
</p>

StartMenu4Macは、アプリ一覧とピン留めしたアプリ・フォルダーを並べて使える、macOSのメニューバーアプリです。Windowsのスタートメニューに近い操作を提供します。
このアプリケーションは、[Windhawk](https://github.com/ramensoftware/windhawk)の「SideBySide2」に強く触発されました。

現在はベータ版です。機能や動作は変更される可能性があります。さまざまなMac環境での動作確認を歓迎します。

## 主な機能

- インストール済みmacOSアプリの検出（対応するサブフォルダーを含む）
- アプリ名による検索
- アルファベット順に分類したアプリ一覧
- アプリのピン留め、並べ替え、起動
- ピン留めフォルダーの作成と編集
- Dock、メニューバー、グローバルショートカットからメニューを開閉
- macOSのログイン項目によるログイン時の自動起動
- 見つからないピンや、明確に非対応と判定されたアプリへの対応
- 設定、ピン、アプリキャッシュのローカル保存

## 開発状況

現在の開発基準は`0.29.15-beta`（build `102`）です。macOS 15.6を対象としています。バージョン／ビルド番号の正本はXcodeプロジェクトです。このソースリポジトリでは、署名・公証済みバイナリやMac App Store版を配布していません。

## ビルドとチェック

必要な環境はmacOS 15.6以降と、macOS SDKを含むXcodeです。

`StartMenu4Mac.xcodeproj`をXcodeで開くか、次のコマンドでビルドできます。

```bash
xcodebuild -project StartMenu4Mac.xcodeproj -scheme StartMenu4Mac -configuration Debug build CODE_SIGNING_ALLOWED=NO
```

利用可能なビルド・翻訳チェックには`bash scripts/check.sh`を実行してください。プライベートな開発チェックアウトではXCTestも実行しますが、公開用ソースエクスポートには非公開のテスト群を含めないため、そこでの簡易チェックは代わりにDebugビルドを行います。リリースや作業引き継ぎの前には、Debug/Releaseビルドと生成アプリのメタデータ・リソースを検証する`bash scripts/check.sh --full`を実行してください。チェックはローカルで完結し、Git同期を行いません。

## 翻訳

アプリ内の翻訳にはApple標準の`.lproj/Localizable.strings`を使います。翻訳の追加方法とレビューについては[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。
